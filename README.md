<h1 align="center">Smart Switch Light Control</h1>

Home Assistant custom integration that allows you to control lights using a pulse button.
Tap to toggle, hold to change brightness and double tap to change temperature.

## Install via HACS

Add this repository as a custom repository in HACS (category: Integration), then install
"Smart Switch Light Control".
